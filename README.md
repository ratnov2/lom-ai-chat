## Запуск

npm ci
npm run dev

## Архитектура

Один slice хранит `chats`, `messages`, `generationsByChatId`, активный диалог, черновики и позиции чтения. Сущности нормализованы. Позиции чтения существуют только в сессии.

Путь запроса: команда `sendMessage` проверяет текст и блокировку → `requestAccepted` атомарно создаёт сообщения и запрос → listener получает снимок завершённых пар истории → запускает агент → `eventReceived` сверяет chatId, requestId и активную фазу → reducer меняет ответ и фазу → UI отображает состояние.

Фазы: queued, processing, tool_running, streaming, completed, failed, cancelled, interrupted. Отдельного isLoading нет. Список сортируется по пользовательским отправкам.

## Сохранение

История сохраняется в IndexedDB в базе `lom-ai-chat`, object store `snapshots`, запись `current`. Версионированный снимок содержит диалоги, сообщения, черновики и запросы. Позиции чтения остаются в памяти сессии. Запуск ожидает асинхронного чтения и проверки данных перед показом чата.

## Ограничения и улучшения

Агент распознаёт только перечисленные темы и простые формулировки; это не языковая модель. Калькулятор допускает одно бинарное выражение, без скобок и eval. Ответы — обычный текст, без Markdown, HTML и формульного рендера. Нет авторизации, backend, вложений, голоса, удаления и переименования диалогов.

Следующие улучшения: добавить контроль объёма истории и экспорт; выделить устойчивые идентификаторы тем и шагов вместо распознавания текста истории; затем подключить реальный потоковый API через существующий IAgentClient.
Добавить InfinityScroll, перемещение между чатами с сохранением скролла.
